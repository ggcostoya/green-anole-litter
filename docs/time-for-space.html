Overview

The goal of this analysis is to estimate the threshold temperature at which Green Anoles (Anolis carolinensis) retreat to the leaf litter and are no longer observed in the tree canopy. To determine this threshold, we will combine field survey and iButton-based temperature data and later statistically analyze the relationship between temperature and both presence and abundance of Green Anoles.

The dataset structure is as follows:

  • In survey, each row corresponds to a unique lizard observation. Some rows are left completely as NA indicating that no lizards were observed during that survey. It contains the following columns:
    • year: numeric year of the survey.
    • doy: numeric day of year of the survey.
    • mod: numeric minute of the day in which each observation occured.
    • air_temp: numeric air temperature in degrees Celsius at the time of the observation.
    • body_temp: numeric body temperature of the lizard in degrees Celsius at the time of the observation.
    • start_mod & end_mod: numeric start and end time of the survey in minutes since midnight
    • n_participants: numeric number of participants in the survey.
  • In ibutton, each row corresponds to a unique temperature observation from an iButton data logger. It contains the following columns:
    • location: character location where the iButton was deployed. Each value corresponds to a unique city including ATL, GNV, MIA, ORL, PSL.
    • id: numeric unique identifier for each iButton within each location.
    • year, doy, mod: same as in survey.
    • microhabitat: character microhabitat in which the iButton was deployed including leaflitter, branch.

Next we filter the iButton data to match the survey data and combine the two datasets. The resulting dataset contains the mean temperature for each microhabitat during each survey. In this case, we only use data from ATL to match the survey data, but we will use the complete dataset for other analyses.

Code for Processing Survey and iButton Data
# filter iButton data to match survey data
ibutton_survey <- ibutton |>
  filter(location == "ATL") |>
  mutate(year = year + 2000) |> # resolve year formatting issue
  filter(year >= min(survey$year) & year <= max(survey$year)) |>
  filter(paste(year, doy) %in% paste(survey$year, survey$doy)) |>
  left_join(
    survey |>
      select(year, doy, start_mod, end_mod) |>
      unique(),
    by = c("year", "doy")
  ) |>
  # one survey went past midnight, so we cap end_mod at 1440 (24 hours)
  mutate(end_mod = ifelse(end_mod > 1440, 1440, end_mod)) |>
  filter(mod >= start_mod & mod <= end_mod) |>
  group_by(year, doy, microhabitat) |>
  filter(temp > -10) |> # remove erroneous iButton readings
  summarise(
    mean_temp = mean(temp, na.rm = TRUE),
    .groups = "drop"
  ) |>
  pivot_wider(
    names_from = microhabitat,
    values_from = mean_temp
  ) |>
  rename(
    branch_temp = branch,
    litter_temp = leaflitter
  )

# combine survey and iButton data
survey_ibutton <- survey |> left_join(ibutton_survey, by = c("year", "doy"))

Estimating Retreating Temperature Threshold

In the following analyses, we model the relationship between branch temperature and lizard observation/abundance to identify temperature thresholds at which lizards retreat due to cold temperatures. We focus on branch temperature as a representative of the overall air temperature the lizard experiences in its “typical” habitat. We use two different models to estimate these thresholds: a binomial logistic regression and a Poisson regression. From each model fit, we then extract the most relevant temperature thresholds for lizard retreating behavior.

# predict temperature thresholds
tibble(probability = c(0.5, 0.1, 0.05, 0.01)) |>
  mutate(
    logit = log(probability / (1 - probability)),
    temp_mean_est = round((logit - coef(presence_model)[1]) / coef(presence_model)[2], 2), # nolint
    temp_lower_est = round((logit - coef(presence_model)[1] - 1.96 * summary(presence_model)$coefficients[2, 2]) / coef(presence_model)[2], 2), # nolint
    temp_upper_est = round((logit - coef(presence_model)[1] + 1.96 * summary(presence_model)$coefficients[2, 2]) / coef(presence_model)[2], 2) # nolint
  ) |>
  select(probability, temp_mean_est, temp_lower_est, temp_upper_est) |>
  mutate(temp = paste(temp_mean_est, " (", temp_lower_est, " - ", temp_upper_est, ")", sep = "")) |>
  select(probability, temp) |>
  rename(
    `Probability of Observation` = probability,
    `Temp. (°C)` = temp
  ) |>
  kable() |>
  kable_styling(
    full_width = FALSE,
    position = "center"
  )

The model, as expected, shows a significant positive effect of branch temperature on observation probability. The table above shows the estimated branch temperature thresholds at which we expect to observe lizards with different probabilities. For example, we expect to see at least one lizard during a survey 50% of the time when the branch temperature is around 12.72 °C, and we expect to see at least one lizard during a survey 10% of the time when the branch temperature is around 6.6 °C.

Leaf litter buffering across latitudes

Code 
# process iButton data
ibutton_processed <- ibutton |>
  filter(temp > -10) |> # remove outliers tude to error
  filter(doy > 330 | doy < 60) |> # focus on winter months
  group_by(location, year, doy, id, microhabitat) |>
  summarise(
    min_temp = min(temp, na.rm = TRUE),
    .groups = "drop"
  ) |>
  group_by(location, year, id, microhabitat) |>
  summarise(
    mean_min_temp = mean(min_temp, na.rm = TRUE),
    min_min_temp = min(min_temp, na.rm = TRUE),
    .groups = "drop"
  ) |>
  mutate(
    lat = case_when(
      location == "MIA" ~ 25.7617,
      location == "PSL" ~ 27.305,
      location == "ORL" ~ 28.5383,
      location == "GNV" ~ 29.6516,
      location == "ATL" ~ 33.7490
    )
  )
