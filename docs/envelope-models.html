Leaf litter temperatures predict the green anole’s poleward range limit

Overview

We hypothesize that the green anole’s poleward range edge is set not by the cold air temperatures in the canopy, but by the thermal conditions within the leaf litter where lizards overwinter. In this vignette, we use mechanistic envelope models to evaluate which microclimate and forest cover threshold best predict the green anole’s range, both across its entire range and near its poleward range edge. We use the green anole’s range and the minimum annual body temperatures in the canopy and at different depths in the leaf litter that we estimated in the biophysical models vignette.

Mechanistic envelope models

Envelope models compare the capacity of a set of threshold values across environmental variables to predict a species’ range. These models assign a binary suitability score to each spatial cell based on where the values of the environmental variables fall relative to the thresholds of interest. By comparing the inferred suitability map against the observed range cell-by-cell, we can obtain the True Skill Statistic (TSS), which evaluates model performance as a function of both sensitivity and specificity (i.e., its ability to simultaneously predict presence and absence):

\[ TSS = \frac{TP}{TP + FN} + \frac{TN}{TN + FP} - 1 \]

where \(TP\), \(FN\), \(TN\) and \(FP\) are the number of true positives, false negatives, true negatives and false positives, respectively. TSS ≤ 0 indicates a predictive ability no better than random, while a value of 1 indicates a perfect match. Thus, if a set of thresholds A yields a greater TSS than a set B, we can infer that the species’ range is more likely determined by A than by B.

Traditionally, envelope models rely on macroclimatic layers (e.g., air temperatures) and statistically identified thresholds. Instead, our mechanistic approach uses the minimum annual body temperatures estimated with our biophysical models for each microclimate and sets the threshold based on the green anole’s physiology. Specifically, we deem a cell unsuitable if the minimum annual body temperature in a given microclimate falls below 0 °C, which we assume is the lethal cold threshold for the green anole. Because the green anole is arboreal during its active season, we also include forest cover as a second variable, but we do not set its threshold a priori. Instead, we evaluate every forest cover threshold between 0 and 100% at 5% intervals. The combination of microclimate and forest cover threshold that yields the highest TSS is the most probable determinant of the green anole’s range.

What limits a species’ range at its poleward edge might differ from what limits it within its core. For this reason, we repeat the analysis across four spatial extents defined by the minimum annual temperatures in the canopy (1.8 m):

  1. Entire range: all spatial cells for which we obtained estimates from our biophysical models.

  2. Behavioral threshold: only cells where canopy temperatures fall below the retreating temperature we inferred from our surveys (Tret = 8.06 °C, at the average photoperiod of our surveys; see Green anoles retreat to the leaf litter to avoid extreme cold).

  3. Soft physiological threshold: only cells where canopy temperatures fall below the lowest population-average CTmin of the species (6.8 °C).

  4. Hard physiological threshold: only cells where canopy temperatures fall below 0 °C.

# range edge: boundaries between adjacent land cells where the green anole is
# present and absent. Unlike a contour, this does not trace the coastline. The
# range polygon also stops slightly short of the coast in many places, leaving
# a narrow fringe of "absent" coastal cells; we ignore boundaries with absent
# cells within `coast_buffer` cells (~4 km each) of the coast so that the line
# only shows the inland range edge
range_edge <- function(cells, res = 1 / 24, coast_buffer = 3,
                       min_neighbors = 10) {
  grid <- cells |>
    mutate(
      i = round((lon - min(lon)) / res),
      j = round((lat - min(lat)) / res),
      key = paste(i, j)
    ) |>
    select(i, j, key, lon, lat, presence)
  shift_key <- function(df, di, dj) paste(df$i + di, df$j + dj)
  steps <- list(c(1, 0), c(-1, 0), c(0, 1), c(0, -1))

  # cells within coast_buffer cells of the coast (i.e., of a missing cell)
  near_coast <- !Reduce(
    `&`, lapply(steps, \(k) shift_key(grid, k[1], k[2]) %in% grid$key)
  )
  for (b in seq_len(coast_buffer - 1)) {
    near_keys <- grid$key[near_coast]
    near_coast <- near_coast | Reduce(
      `|`, lapply(steps, \(k) shift_key(grid, k[1], k[2]) %in% near_keys)
    )
  }
  grid$near_coast <- near_coast

  # boundaries with the eastern and northern neighbor of each cell
  neighbor <- function(di, dj) {
    grid |>
      mutate(i = i - di, j = j - dj) |>
      select(i, j, presence_n = presence, near_coast_n = near_coast)
  }
  inland_boundary <- function(df) {
    df |>
      filter(presence != presence_n) |>
      # skip boundaries where the absent cell is in the coastal fringe
      filter(!ifelse(presence == 0, near_coast, near_coast_n))
  }
  east <- grid |>
    inner_join(neighbor(1, 0), by = c("i", "j")) |>
    inland_boundary() |>
    transmute(
      x = lon + res / 2, xend = lon + res / 2,
      y = lat - res / 2, yend = lat + res / 2
    )
  north <- grid |>
    inner_join(neighbor(0, 1), by = c("i", "j")) |>
    inland_boundary() |>
    transmute(
      x = lon - res / 2, xend = lon + res / 2,
      y = lat + res / 2, yend = lat + res / 2
    )
  edges <- bind_rows(east, north)

  # drop isolated specks (e.g., small islands): keep segments with at least
  # `min_neighbors` other segments within 0.25 degrees, which is always true
  # along the continuous range edge
  mid_x <- (edges$x + edges$xend) / 2
  mid_y <- (edges$y + edges$yend) / 2
  n_close <- vapply(seq_len(nrow(edges)), \(k) {
    sum((mid_x - mid_x[k])^2 + (mid_y - mid_y[k])^2 < 0.25^2) - 1
  }, numeric(1))
  edges[n_close >= min_neighbors, ]
}

thresh_names <- unique(micro_df$thresh)
veg <- seq(0, 1, by = 0.05)

# loop through
for (i in seq_len(nrow(tss_grid))) {

  # filter data of interest
  micro_df_sub <- micro_df |> filter(z == tss_grid$z[i])
  if (tss_grid$thresh[i] == "below_zero") {
    micro_df_sub <- micro_df_sub |> filter(thresh == "below_zero")
  } else if (tss_grid$thresh[i] == "below_ctmin") {
    micro_df_sub <- micro_df_sub |> 
      filter(thresh %in% c("below_zero", "below_ctmin"))
  } else if (tss_grid$thresh[i] == "below_tret") {
    micro_df_sub <- micro_df_sub |>
      filter(thresh %in% c("below_zero", "below_ctmin", "below_tret"))
  }

  tss_value <- micro_df_sub |>
    mutate(
      pred = min_annual_body_temp > 0 & veg > tss_grid$veg[i]
    ) |>
    summarise(
      tp = sum(pred & presence),
      fp = sum(pred & !presence),
      fn = sum(!pred & presence),
      tn = sum(!pred & !presence)
    ) |>
    mutate(tss = (tp / (tp + fn)) + (tn / (tn + fp)) - 1) |>
    pull(tss)
  tss_grid$tss[i] <- tss_value

  # track progress
  if (i %% 100 == 0) {
    message(paste("Processed", i, "of", nrow(tss_grid), "rows"))

Contribution of each variable and variation along the range edge

To better understand what drives the predictive performance of the mechanistic envelope models, we run two additional sets of analyses. First, we evaluate the predictive capacity of each variable on its own. Second, we test whether the microclimate and forest cover thresholds that best predict the green anole’s range are consistent along its range edge, by repeating the analysis within narrow longitudinal bands.

## Note: This code chunk is not evaluated as it takes a long time to run.
## The output is saved in the `data/tss_single.rds` and `data/tss_bands.rds`
## files.

# spatial extents (nested sets of threshold classes)
extents <- list(
  below_zero = "below_zero",
  below_ctmin = c("below_zero", "below_ctmin"),
  below_tret = c("below_zero", "below_ctmin", "below_tret"),
  rest_of_range = c("below_zero", "below_ctmin", "below_tret", "rest_of_range")
)
veg_thresholds <- seq(0, 1, by = 0.05)

# TSS from predicted and observed presences
calc_tss <- function(pred, presence) {
  tp <- sum(pred & presence)
  fn <- sum(!pred & presence)
  tn <- sum(!pred & !presence)
  fp <- sum(pred & !presence)
  (tp / (tp + fn)) + (tn / (tn + fp)) - 1
}

# presence as logical and 1-degree longitudinal bands
micro_df <- micro_df |>
  mutate(
    presence = presence == 1,
    band = floor(lon)
  )

# 1) single-variable models across each spatial extent
# forest cover alone (forest cover does not depend on the microclimate, so we
# use one row per cell)
cells <- micro_df |> filter(z == 1.8)
tss_forest <- expand_grid(thresh = names(extents), veg = veg_thresholds) |>
  mutate(
    tss = map2_dbl(thresh, veg, \(e, v) {
      d <- cells[cells$thresh %in% extents[[e]], ]
      calc_tss(d$veg > v, d$presence)
    }),
    model = "forest"
  )

# temperature alone
tss_temp <- expand_grid(
  thresh = names(extents),
  z = sort(unique(micro_df$z))
) |>
  mutate(
    tss = map2_dbl(thresh, z, \(e, zz) {
      d <- micro_df[micro_df$z == zz & micro_df$thresh %in% extents[[e]], ]
      calc_tss(d$min_annual_body_temp > 0, d$presence)
    }),
    model = "temperature"
  )

saveRDS(bind_rows(tss_forest, tss_temp), "data/tss_single.rds")

# 2) full models (temperature + forest cover) within each longitudinal band
tss_bands <- map(sort(unique(micro_df$z)), \(zz) {
  d <- micro_df |>
    filter(z == zz) |>
    mutate(pred_temp = min_annual_body_temp > 0)
  map(names(extents), \(e) {
    d_ext <- d |> filter(thresh %in% extents[[e]])
    map(veg_thresholds, \(v) {
      d_ext |>
        mutate(pred = pred_temp & veg > v) |>
        group_by(band) |>
        summarise(
          n_pres = sum(presence),
          n_abs = sum(!presence),
          tp = sum(pred & presence),
          fn = sum(!pred & presence),
          tn = sum(!pred & !presence),
          fp = sum(pred & !presence),
          .groups = "drop"
        ) |>
        mutate(
          tss = (tp / (tp + fn)) + (tn / (tn + fp)) - 1,
          veg = v
        )
    }) |>
      list_rbind() |>
      mutate(thresh = e)
  }) |>
    list_rbind() |>
    mutate(z = zz)
}) |>
  list_rbind() |>
  select(thresh, band, z, veg, n_pres, n_abs, tss)

Longitudinal bands

The factors that limit a species’ range can vary along its range edge. For example, the western limit of the green anole’s range (Texas and Oklahoma) is likely set by aridity rather than by cold. To test whether the same microclimate and forest cover thresholds predict the range consistently along its edge, we split the study area into 1°-wide longitudinal bands, each spanning the entire latitudinal extent of the study area (and thus its own section of the poleward range edge), and repeat the mechanistic envelope models for every combination of microclimate, forest cover threshold and spatial extent within each band. We only consider bands with at least 10 cells where the green anole is present and 10 where it is absent within a given spatial extent. When several microclimates or forest cover thresholds tie for the highest TSS within a band, we show the full range of tied values.

# boundaries between thermal zones (between adjacent land cells only)
zone_edges <- function(cells, res = 1 / 24) {
  grid <- cells |>
    mutate(
      i = round((lon - min(lon)) / res),
      j = round((lat - min(lat)) / res)
    ) |>
    select(i, j, lon, lat, thresh)
  neighbor <- function(di, dj) {
    grid |>
      mutate(i = i - di, j = j - dj) |>
      select(i, j, thresh_n = thresh)
  }
  east <- grid |>
    inner_join(neighbor(1, 0), by = c("i", "j")) |>
    filter(thresh != thresh_n) |>
    transmute(
      x = lon + res / 2, xend = lon + res / 2,
      y = lat - res / 2, yend = lat + res / 2
    )
  north <- grid |>
    inner_join(neighbor(0, 1), by = c("i", "j")) |>
    filter(thresh != thresh_n) |>
    transmute(
      x = lon - res / 2, xend = lon + res / 2,
      y = lat + res / 2, yend = lat + res / 2
    )
  bind_rows(east, north)
}

Finally, we push the analysis above to a much finer resolution, defining spatial extents by latitude instead of by temperature. We split the study area into 0.25°-wide longitudinal bands and, within each band, define a spatial extent for every latitude L at 0.25° intervals, including all cells in the band at or north of L. As we move L south, each extent includes progressively warmer areas, from those just around the poleward range edge to the entire band. Within each band and spatial extent, we again evaluate every combination of microclimate and forest cover threshold, and keep the combination that maximizes TSS. As before, we only consider extents with at least 10 cells where the green anole is present and 10 where it is absent. Because the spatial extents are nested, we calculate the number of true and false positives and negatives for each 0.25° latitudinal class and accumulate them from north to south, which yields the results of all spatial extents at once.

# TSS of every forest cover threshold, for every band and latitudinal extent,
# for one microclimate (counts are accumulated from north to south)
tss_lat_z <- function(zz) {
  d <- micro_df |>
    filter(z == zz) |>
    select(lon, lat, elev, veg, presence, min_annual_body_temp) |>
    inner_join(
      cells_lat |> select(lon, lat, elev, veg, presence, band, lat_class),
      by = c("lon", "lat", "elev", "veg", "presence")
    ) |>
    mutate(presence = presence == 1, pred_temp = min_annual_body_temp > 0)
  map(veg_thresholds, \(v) {
    d |>
      mutate(pred = pred_temp & veg > v) |>
      group_by(band, lat_class) |>
      summarise(
        tp = sum(pred & presence),
        fn = sum(!pred & presence),
        tn = sum(!pred & !presence),
        fp = sum(pred & !presence),
        .groups = "drop"
      ) |>
      right_join(all_classes, by = c("band", "lat_class")) |>
      mutate(across(c(tp, fn, tn, fp), \(x) replace_na(x, 0))) |>
      arrange(band, desc(lat_class)) |>
      group_by(band) |>
      mutate(across(c(tp, fn, tn, fp), cumsum)) |>
      ungroup() |>
      transmute(
        band,
        min_lat = lat_class,
        n_pres = tp + fn,
        n_abs = tn + fp,
        tss = (tp / (tp + fn)) + (tn / (tn + fp)) - 1,
        veg = v
      )
  }) |>
    list_rbind()
}

Minimum leaf-litter depth required in each cell

The maps above assign each cell the optimum of a spatial extent that includes other cells (e.g., all cells to its north), so the color of a cell partly reflects conditions elsewhere. In fact, an optimal leaf-litter depth or forest cover threshold cannot be defined for a single cell: TSS requires both presences and absences, and, for a single cell where the green anole is present, every microclimate that keeps lizards above 0 °C predicts its presence equally well. What we can calculate for each cell independently, using only its own biophysical model estimates, is the minimum leaf-litter depth at which a green anole’s minimum annual body temperature stays above a given threshold. Minimum annual body temperatures never decrease with depth in any cell, so this minimum depth is well defined.
