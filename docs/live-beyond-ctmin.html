Overview

Ectotherms are often assumed to need physiological adaptation to expand their ranges poleward. If that were the case for the green anole, its cold tolerance should track the colder climates it encounters at higher latitudes. Below we test this assumption in two steps. First, we compare how the critical thermal minimum (CTmin) of green anoles and minimum annual temperatures change across the species’ latitudinal range. Second, we combine CTmin data with the geographic ranges of 181 lizard species to quantify how much of each species’ range falls below its CTmin and below 0 °C, and assess whether the green anole is an exceptional case.

CTmin does not scale with climate

Below we demonstrate how the critical thermal minimum (CTmin) of green anoles does not scale with climatic cooling. We do this by comparing empirical CTmin data with the minimum annual temperatures across a latitudinal gradient spanning the range of the green anole.

We collected the CTmin data from 7 locations across the range of A. carolinensis. To measure CTmin, we fitted lizards with a cloacal thermocouple probe, secured it to the base of the tail with surgical tape, and placed them in an experimental chamber submerged in an ice-water bath. Once internal body temperature stabilized after handling, we gradually cooled lizards and, starting at ~15 °C, evaluated the righting reflex at 0.2 °C intervals by placing the lizard on its dorsum and applying gentle pressure to the hind limbs. We recorded CTmin as the core body temperature at which an individual completely lost the capacity to right itself. We also extracted the minimum temperature of the coldest month (BIO6) from WorldClim and obtained the average, minimum and maximum BIO6 values for each 0.1° latitude band within a bounding box defined by the locations where we measured CTmin (+1° in each cardinal direction; +0.5° to the north).

The figure below (Fig. S2 in the manuscript) shows that while BIO6 decreases with latitude, CTmin does not follow this trend, indicating that green anoles are living in climates colder than their physiological cold tolerance.

Below, we perform a linear regression to test whether CTmin and BIO6 scale with latitude at the same rate. We combine both types of temperature values into a single dataset and fit the following model:

\[ T \sim Normal(t_i, \sigma) \]

\[ t_i = \alpha + \beta_L \cdot L_i + \beta_C \cdot C_i + \beta_{L \cdot C} \cdot L_i \cdot C_i \]

where temperature (\(T\)) depends on latitude (\(L\)), an indicator variable (\(C\)) identifying the nature of the temperature values (\(C = 0\) for BIO6 and \(C = 1\) for CTmin), and their interaction. If the interaction term (\(\beta_{L \cdot C}\)) is positive and significant, CTmin scales with latitude at a significantly shallower rate than BIO6. The results of this model are presented in Table S2 of the manuscript.

Data processing

We compiled a dataset of CTmin and elevational limits for 181 lizard species, representing 17 families and 46 genera. We obtained CTmin estimates from the GlobTherm database and complemented them with two datasets focused specifically on Anolis lizards (Bodensteiner et al. 2024; Salazar et al. 2025). We then obtained elevational range limits, substrate use (arboreal, semi-arboreal or other) and the identifiers linking each species to its range map in the GARD database from SquamBase. The script used to compile this dataset (process-ctmin-lizards-data.R) is stored in the raw_data folder. For A. carolinensis, we set CTmin to 6.8 °C, the lowest population-average CTmin we measured (Knoxville, TN).

Below we combine data on the CTmin and elevational limits of globally distributed lizards to find the total area and proportion of each species’ range that is below their CTmin and below 0°C. We also calculate the maximum latitude at which each species can occur above their CTmin and above 0°C.

For each species, we:

  1. Crop and mask global BIO6 and elevation rasters (2.5’ resolution, WorldClim) to the species’ range polygon from the GARD database.

  2. Keep only cells whose elevation falls within the species’ elevational limits.

  3. Convert each cell to its area in km2 (deg_to_area()), accounting for the fact that cells shrink with latitude because the Earth is an ellipsoid.

  4. Sum the area of all cells, of cells where BIO6 < CTmin and of cells where BIO6 < 0 °C, and divide the latter two by the total area to obtain proportions.

Lastly, we calculate the global mean (± SD) BIO6 for every degree of absolute latitude, which we use as a reference in the plots below.

ranges <- readRDS("raw_data/ranges_vector.rds")

# filter ranges to only include lizard species with CTmin data
ctmin_lizards_ranges <- ranges[ranges$TaxonID %in% ctmin_lizards$gard_id, ]

# define function to conver lat-lon degree cell to km^2
deg_to_area <- function(lat, delta_lat = 2.5 / 60, delta_lon = 2.5 / 60) {
  
  # unit conversions
  lat_rad <- lat * pi / 180 # convert to radians

  # define constants
  equat_radius <- 6378.1370 # equatorial radius
  polar_radius <- 6356.7523142 # polar radius
  flat_factor <- 1 / 298.257223563 # flattening factor

  # radius curvature in the meridian
  e_sq <- (equat_radius^2 - polar_radius^2) / equat_radius^2
  denominator <- (1 - e_sq * sin(lat_rad)^2)^(1.5)
  m <- (equat_radius * (1 - e_sq)) / denominator

  # set length of 1 degree latitude in km
  km_per_degree_lat <- m * (pi / 180)
  lat_dist <- km_per_degree_lat * delta_lat

  # Calculate distance of 1 degree longitude along the parallel
  dist_km <- (pi / 180) * equat_radius * cos(lat_rad) / sqrt(1 - (2 * flat_factor - flat_factor^2) * sin(lat_rad)^2) # nolint
  lon_dist <- delta_lon * dist_km

  # Return cell area in km^2
  lat_dist * lon_dist
}

# define results list to extract data
results_list <- vector("list", nrow(ctmin_lizards))

for (i in seq_along(ctmin_lizards$gard_id)) {

  # get species range and ctmin
  range <- ctmin_lizards_ranges[ctmin_lizards_ranges$TaxonID == ctmin_lizards$gard_id[i], ] # nolint
  ctmin <- ctmin_lizards$ctmin[i]
  min_elev <- ctmin_lizards$min_elev[i]
  max_elev <- ctmin_lizards$max_elev[i]

  # crop BIO6 and elevation rasters to species range
  bio6_crop <- terra::crop(terra::mask(bio6, range), range)
  elev_crop <- terra::crop(terra::mask(elev, range), range)

  # filter all areas within range and within elevation limits
  valid_cells <- which(
    !is.na(bio6_crop[]) &
      !is.na(elev_crop[]) &
      elev_crop[] >= min_elev &
      elev_crop[] <= max_elev
  )

  # filter valid cells in BIo6 raster
  bio6_crop_filtered <- bio6_crop[valid_cells]
  bio6_crop_filtered <- bio6_crop_filtered$bio_6

  # extract coordinates of valid cells
  coords <- terra::xyFromCell(bio6_crop, valid_cells)[, "y"]
  dist <- deg_to_area(abs(coords))

  # get metrics
  total_area <- sum(dist)
  below_ctmin_area <- sum(dist[bio6_crop_filtered < ctmin])
  below_0_area <- sum(dist[bio6_crop_filtered < 0])
  below_ctmin_prop <- below_ctmin_area / total_area
  below_0_prop <- below_0_area / total_area
  max_lat_above_ctmin <- ifelse(
    below_ctmin_area %in% c(0, 1),
    NA,
    max(abs(coords[bio6_crop_filtered >= ctmin]), na.rm = TRUE)
  )
  max_lat_above_0 <- ifelse(
    below_0_area %in% c(0, 1),
    NA,
    max(abs(coords[bio6_crop_filtered >= 0]), na.rm = TRUE)
  )

  # store results in list
  results_list[[i]] <- data.frame(
    family = ctmin_lizards$family[i],
    genus = ctmin_lizards$genus[i],
    species = ctmin_lizards$species[i],
    ctmin = ctmin,
    substrate = ctmin_lizards$substrate_type[i],
    min_lat = min(abs(terra::ext(range)[3:4])),
    max_lat = max(abs(terra::ext(range)[3:4])),
    total_area = total_area,
    below_ctmin_area = below_ctmin_area,
    below_0_area = below_0_area,
    below_ctmin_prop = below_ctmin_prop,
    below_0_prop = below_0_prop,
    max_lat_above_ctmin = max_lat_above_ctmin,
    max_lat_above_0 = max_lat_above_0
  )

  # clear up memory
  rm(
    range, ctmin, min_elev, max_elev, bio6_crop, elev_crop,
    valid_cells, bio6_crop_filtered, coords, dist,
    total_area, below_ctmin_area, below_0_area, below_ctmin_prop,
    below_0_prop, max_lat_above_ctmin, max_lat_above_0
  )
  terra::tmpFiles(remove = TRUE)
  gc()

  # print progress
  cat("Processed species", i, "of", nrow(ctmin_lizards), "\n")

}
