# A major behavioral innovation enabled the poleward range expansion of a tropical ectotherm beyond its physiological limits

This repository contains the supplementary code and data for our manuscript on how the American green anole (*Anolis carolinensis*) expanded its range from the tropics into temperate North America by retreating into the leaf litter during winter.

## 👉 [Start Here](https://ggcostoya.github.io/green-anole-litter/)

The documentation for this project is a website that walks through every analysis in the manuscript. Please begin at the [**Start Here**](https://ggcostoya.github.io/green-anole-litter/) page, which describes the study, how the website is organized, and the datasets included in this repository.

If you have cloned this repository, the same page is available offline at `docs/index.html`.
